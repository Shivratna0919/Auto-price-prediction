# 🚗 Car Price Prediction System

A Machine Learning web application that predicts car prices based on vehicle details using a trained **Decision Tree Regressor** and **Streamlit**.

## ✨ Features

* 🚗 Car price prediction
* 📊 Vehicle specification input form
* 🤖 Decision Tree Machine Learning model
* ⚡ Instant price prediction
* 🎨 Modern dashboard UI with car images
* 📋 Vehicle input summary
* 💻 Interactive web application

## 🧠 ML Pipeline

```text
Vehicle Details
      ↓
Input Preprocessing
      ↓
Trained Decision Tree Model
      ↓
Price Prediction
      ↓
Predicted Car Price
```

## 🚀 Run Project

### 1. Install dependencies

```bash
pip install streamlit pandas scikit-learn
```

### 2. Keep the required files together

Make sure `app.py`, `decision_tree_model.pkl`, and `features.pkl` are in the same project folder.

### 3. Run the application

```bash
streamlit run app.py
```

The application will open in your web browser.
